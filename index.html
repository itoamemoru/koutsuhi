⚠ はじめにお読みください

  • 位置情報はどこにも送りません。計算はこのスマホ（パソコン）の中だけで行い、閉じれば消えます。
  • 「全部おまかせ」ではなく、入力を手伝うサポートツールです。できあがった内容は必ず自分の目で確認し、間違っていたら修正してから提出してください。
  • 使うのは、本人が自分の位置情報を使うことに同意した場合だけです。会社が社員のタイムラインを集めることはありません。
  • 社用車・乗り合わせ・私用の移動は、自動では区別できません。外す日・直す距離は本人が入れてください。

ℹ 使い方とコツ

タイムラインの書き出し方
  1. 設定 → 位置情報 → 位置情報サービス → タイムライン
  2. タイムライン データをエクスポート → 続行
  3. 保存先は ダウンロード でOK（タイムライン.json ができます）
  4. このアプリの「JSONファイルを選ぶ」で、そのファイルを選びます

※ 月が終わってから書き出してください。
※ 機種によってメニューの名前が少し違います。設定の検索で「タイムライン」と入れると早いです。
※ タイムラインはスマホの中にだけ保存されます。タイムラインの画面で「バックアップ」をオンにしておくと、機種変更でも消えません。

GPSの精度を上げる方法

スマホは電池節約のためGPSをあまり使わず、記録が抜けたり手段を取り違えたりします。次の設定でかなり良くなります。

  1. 「Google 位置情報の精度」をオン：設定 → 位置情報 → 位置情報サービス
  2. Wi-Fiスキャン・Bluetoothスキャンをオン：同じ画面
  3. Googleマップに「常に許可」＋「正確な位置情報」：設定 → アプリ → マップ → 権限 → 位置情報
  4. Googleマップの電池の制限を外す：アプリ → マップ → 電池 → 制限なし。運転する日は省電力モードをオフに
  5. タイムラインがオンか確認：位置情報サービス → タイムライン
  6. 運転中はスマホをカバンの奥に入れない。長距離はGoogleマップのナビを使うと記録が細かくなりやすい
  7. 月初と月末にメーターを写真で残す（月の合計の答え合わせ）
印の意味
  • 帰りの記録なし：最後が自宅から離れた所で終わっている
  • 距離不足の疑い：途中の記録が抜けている
  • 元データ要確認：車かバス・電車かはっきりしない区間がある（車として数えています）
  • 要確認：100㎞以上。社用車・乗り合わせでないか

印は確認用で、申請書には入りません。
